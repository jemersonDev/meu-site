# Jemerson Lima — Portfólio Full Stack

Portfólio profissional de Jemerson Lima, desenvolvedor Full Stack em Uberaba–MG. O projeto apresenta serviços, processo de trabalho e cases de sites, sistemas web e automações com inteligência artificial.

## Projetos em destaque

- [Marcus Tattoo](https://projeto-marcus-tato.vercel.app/) — site interativo para estúdio de tatuagem
- [Desafio DevClub](https://devclub-jemerson.netlify.app/) — landing page premium responsiva
- JemTech Sports — aplicativo para organização de partidas de futebol

## Tecnologias

Next.js 15, React 19, TypeScript, Tailwind CSS 4 e GSAP.

## Executar localmente

```bash
cd jemtech-nextjs
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Validação

```bash
npm run typecheck
npm run build
```

O GitHub Actions executa essas verificações automaticamente em Pull Requests.

## Estrutura

O aplicativo está em `jemtech-nextjs/`. Ao configurar o projeto na Vercel, use essa pasta como **Root Directory**.
